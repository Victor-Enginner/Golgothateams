# GOLGOTHATEAMS

Hub de comando para **bug bounty** e **ethical hacking** — app estático de página única, sem build e sem dependências externas. Estado salvo no navegador (localStorage).

## Abas
Comando · Roadmap (cronograma) · Setup (Termux / Windows+Kali / Zorin) · Arsenal · Projetos (kanban) · Progresso · Comandos · Playbook (9 falhas) · Modelos LLM.

## Rodar local
Abra `index.html` no navegador. Só isso.

## Deploy
- **Vercel:** importe este repositório → preset *Other* → Deploy. O `index.html` na raiz é servido direto.
- **GitHub Pages:** Settings → Pages → Source: `main` / root.

> Uso exclusivo para estudo, pesquisa e auditorias **autorizadas**. Acesso não autorizado é crime (Lei 12.737/2012, art. 154-A).
